Вопросы

Коротко о главном.
Сколько это стоит?

Нисколько. Сборка, лаунчер и сервер бесплатны. Лицензия Minecraft не нужна — у проекта собственная система аккаунтов.

Почему вход только через лаунчер?

На сервере своя авторизация: ник, пароль и скины хранятся в аккаунт-системе проекта. Лаунчер сам настраивает клиент, поэтому зайти можно одной кнопкой.

Мой прогресс сохранится при обновлении?

Да. Обновления сборки не трогают миры, скриншоты и настройки. Канал обновлений подписан Ed25519, файлы проверяются по SHA-256.

Есть ли версия для Steam Deck?

Да, для SteamOS есть отдельная сборка с готовой раскладкой — смотри релизы steamdeck на GitHub.

Где взять лаунчер?

На странице релизов: github.com/bodia229/bronzepanther-launcher/releases — бери последний установщик Windows.
