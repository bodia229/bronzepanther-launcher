# BronzePanther Launcher

Русский лаунчер сообщества **BronzePanther** для Windows 10/11 x64.

## Скачать

**[Скачать установщик BronzePanther](https://github.com/bodia229/bronzepanther-launcher/releases/latest)**

[Все выпуски](https://github.com/bodia229/bronzepanther-launcher/releases)

Установи лаунчер, зарегистрируйся или войди в разделе «Аккаунт» и нажми «Играть». Для первой подготовки нужен интернет: необходимые Minecraft, NeoForge и Java 25 будут подготовлены автоматически. Актуальный адрес сервера поступает от администратора автоматически.

## Сборки

| Сборка | Статус |
|---|---|
| Техномагия RPG | Доступна — Minecraft 26.1.2, NeoForge 26.1.2.122; 55 модов, 233 квеста, 19 глав |
| Индустрия | Скоро |
| Приключения | Скоро |

В Техномагии RPG есть магия, технологии, Applied Energistics 2, Powah, Industrial Neo, Twilight Forest, прокачка персонажа и удобства для инвентаря.

## Обновления

При включённом автообновлении лаунчер проверяет канал перед запуском. Обновление самого приложения предлагается отдельно с перезапуском. Пакеты проверяются по подписанному каналу Ed25519 и контрольным суммам SHA-256; миры, скриншоты и личные настройки сохраняются.

## Аккаунты и скины

Ник закрепляется за аккаунтом. В лаунчере доступны вход по паролю, запоминание зашифрованной сессии, загрузка PNG-скина и предпросмотр Steve/Alex. После изменения скина перезайди в игру. Для сервера сообщества требуется лаунчер 1.1.0 или новее.

Аккаунты обслуживает сервис сообщества, работающий на компьютере владельца. Вход через Microsoft и Realms не реализованы.

Неофициальный проект сообщества, не связанный с Mojang или Microsoft. Моды и библиотеки сохраняют собственные лицензии.
